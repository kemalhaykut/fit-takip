# Fit Takip

Koyu temalı kişisel antrenman takip uygulaması (Android, Flutter).

- Takvim: günlük bölge kaydı, Bu Ay / Toplam sayaçları
- Programım: bölgeler, hareketler (set × tekrar), set ağırlıkları ve notlar
- Ölçümlerim: tarih bazlı kilo ve grafik
- Kas Haritası: haftalık ön/arka vücut ısı haritası
- Profilim, 6 tema, dinlenme sayacı (30–120 sn)

APK, `main` dalına her yüklemede GitHub Actions ile otomatik derlenir ve **Releases** bölümüne konur.

Fotoğraflar: Unsplash (Unsplash Lisansı) — derleme sırasında `tools/download_photos.sh` ile indirilir.
